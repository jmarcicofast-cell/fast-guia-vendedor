Como usar: clique em qualquer célula para editar direto na tabela. Verde = FAST mais barata que o concorrente naquela linha; vermelho = concorrente mais barato. A coluna "Posição da FAST" mostra onde ela fica entre todos os preços coletados para o item, e a coluna "Anexos" guarda o print/PDF que comprova cada preço. Use "Visão geral" para comparar o desempenho da FAST entre as regiões, e "Controle de Aço" para lançar as vendas de Televendas Porto, Lojas Rio e Atacado B2B num só lugar — cada lançamento tem o número do chamado de abastecimento, pra saber se já foi pedido reposição daquele item. Os dados de MG foram carregados a partir da planilha de 17/09 — confira e ajuste o que precisar.
